# ⚡ Terabox Auto Clicker Multi (v0.3.7) 사용 설명서

## 🚀 1. 빠른 시작 (Getting Started)

1. **에뮬레이터 실행**: 매크로를 적용할 안드로이드 에뮬레이터(예: MSI App Player, LDPlayer 등)를 켜고 대상 앱을 실행합니다.
2. **프로그램 실행**: `TeraboxClicker.exe`를 실행합니다. (별도 ADB 설치 불필요, 내장 바이너리 자동 사용)
3. **디바이스 연결 및 시작**:
   - 상단 툴바의 **`🔗 전체 연결`** 버튼을 누르거나, 각 인스턴스 탭에서 **`Connect Device`**를 클릭합니다.
   - `Status: Connected`로 상태가 변경되면 **`▶ 전체 시작`** 또는 개별 탭의 **`Start Clicker`**를 눌러 자동 클릭을 시작합니다.

## 🎛️ 2. 상단 글로벌 툴바 및 다중 인스턴스 관리

여러 개의 에뮬레이터를 띄워 동시에 자동 클릭을 수행할 수 있도록 다중 탭 인터페이스를 제공합니다.

### 🔹 상단 글로벌 툴바 버튼
* **`🔗 전체 연결`**: 열려 있는 모든 인스턴스 탭의 ADB 디바이스 연결을 일괄 시도합니다.
* **`▶ 전체 시작`**: 연결된 모든 인스턴스의 자동 클릭 루프를 한 번에 시작합니다.
* **`⏹ 전체 중지`**: 동작 중인 모든 인스턴스의 클릭커를 일괄 정지합니다.
* **`➕ 인스턴스 탭 추가`**: 새로운 에뮬레이터 인스턴스 탭을 추가할 수 있는 팝업창을 엽니다.

### 🔹 인스턴스 탭 추가 다이얼로그 (`AddInstanceWindow`)
* **스마트 디바이스 정규화 및 중복 제거**: 실행 중인 에뮬레이터 포트(`5555`, `5557`, `5559`, `62001`, `7555` 등)를 자동 스캔합니다. 동일 인스턴스가 `127.0.0.1:5555`와 `emulator-5554`로 중복 잡히는 경우 IP 형식으로 깔끔하게 통합하여 표시합니다.
* **`➕ 선택 항목 탭 추가`**: 선택한 디바이스들을 각각 독립된 탭으로 생성합니다.
* **`⚡ 전체 추가 & 자동 연결`**: 감지된 모든 디바이스 탭을 생성하고 즉시 ADB 연결까지 원클릭으로 수행합니다.
* **수동 주소 입력**: 목록에 없는 특수 포트/원격 디바이스는 `직접 입력 (IP:Port)` 창에 주소를 입력하여 추가할 수 있습니다.

### 🔹 개별 인스턴스 탭 제어
* **Device 선택/변경**: 탭 상단의 드롭다운에서 연결할 디바이스를 변경할 수 있습니다.
* **`❌ Delete Tab`**: 불필요한 인스턴스 탭을 닫습니다. (최소 1개의 탭 유지 안전장치 적용)
* **`📜 Activity Log`**: 해당 인스턴스의 화면 캡처, 템플릿 매칭 결과, 유사도, 클릭 좌표, 액션 수행 이력을 실시간으로 확인합니다.

## ⏱️ 3. 실시간 타이머 및 상태 정보 바

각 인스턴스 탭 헤더 바로 아래에 3개의 **실시간 상태 카드**가 제공되어 프로그램의 현재 동작 상태를 0.1초 단위로 한눈에 파악할 수 있습니다.

| 카드 | 상태 및 표시 내용 | 설명 |
| :--- | :--- | :--- |
| **⚡ 미매칭 대기 시간** | `⚡ 미매칭 대기: 18.4초 남음 (11.6/30s)`<br>`⚡ 미매칭 동작: 실행 대기 중...`<br>`⚡ 미매칭 동작: 사용 안 함 (OFF)` | 설정된 미매칭 동작(복구 목록 매칭, 랜덤 클릭 등) 실행까지의 **남은 시간 및 경과 시간**을 실시간 카운트다운합니다. |
| **⚠️ 매칭없음 경고 시간** | `⚠️ 매칭없음 경고: 42.1초 남음 (77.9/120s)`<br>`⚠️ 매칭없음 경고: 경고 발생 중! (121.5s 경과)` | 매칭 없음 경고 알림 타임아웃까지의 **남은 시간 및 경과 시간**을 실시간 표시합니다. (15초 미만 시 주황색, 경고 발생 시 빨간색 강조) |
| **🎯 최근 매칭 정보** | `🎯 최근 매칭: btn_ok.png (연속 3회) (2초 전)`<br>`🎯 최근 매칭: popup_close.png [복구] (12초 전)` | 가장 최근 매칭에 성공한 템플릿 이름, **연속 매칭 횟수(동일 템플릿 2회 이상 시)** 및 경과 시간을 실시간으로 표시합니다. |

> `⚡ 미매칭 템플릿` 탭 내부 상단에도 **`⚡ 검사 대기: X.Xs / Ys`** 서브 타이머가 표시되어 복구 템플릿 목록을 확인하면서도 다음 미매칭 검사 타이밍을 바로 알 수 있습니다.

## 📋 4. 템플릿 등록, 관리 및 더블클릭 즉시 실행

등록된 템플릿 이미지는 모든 인스턴스에서 공용으로 탐색하며, 용도에 따라 탭으로 분리하여 관리합니다.

### 📷 A. 신규 템플릿 등록 2단계 마법사 (`+ Create Template` / `+ Create Fallback`)
1. **1단계 (인식 영역 선택)**:
   - 화면 캡처 창이 뜨면 마우스 왼쪽 버튼으로 **인식할 버튼/아이콘 영역을 드래그**한 후 **`Enter`** 또는 **`Space`**를 누릅니다. (취소: `c` 또는 `ESC`)
2. **2단계 (타겟 클릭 위치 지정)**:
   - **기본 중앙 클릭**: 선택한 영역의 정중앙을 클릭하려면 그대로 **`Enter`**를 누릅니다.
   - **커스텀 좌표 클릭**: 버튼 내 특정 모서리나 아이콘 바깥을 클릭해야 하는 경우, **원하는 위치를 마우스로 직접 클릭**한 후 **`Enter`**를 누릅니다.
3. **파일명 입력**: 저장할 이름을 입력하면 이미지 파일(`.png`)과 오프셋 좌표가 원자적으로 저장됩니다. (커스텀 클릭 위치 지정 시 목록에 `🎯(+X, +Y)` 오프셋이 표시됨)

---

### ⚙️ B. 템플릿 관리 기능
* **탭 구분**:
  * **`📋 기본 템플릿` (Primary)**: 매 스캔 주기마다 1순위로 순차 탐색하는 메인 버튼 목록입니다.
  * **`⚡ 미매칭 템플릿` (Fallback)**: 기본 템플릿이 일정 시간 동안 인식되지 않을 때 2차 탈출/복구용으로 탐색하는 목록입니다.
* **👆 템플릿 더블클릭 즉시 실행**:
  * 목록에서 원하는 템플릿 행을 **더블클릭**하면, 현재 에뮬레이터 화면을 즉시 캡처하여 해당 템플릿을 탐색하고 설정된 액션(클릭/더블클릭/뒤로가기)을 즉각 수행합니다. (초록색 시각 피드백 제공)
* **우선순위 드래그 앤 드롭 (`☰`)**:
  * 목록의 **`☰` 핸들**이나 텍스트를 마우스로 끌어 위/아래로 순서를 즉시 변경할 수 있습니다. 상단(1번, 2번 등)부터 우선 매칭을 시도합니다. (Zero-Lag UI 정렬 최적화 적용)
* **동작 모드 토글 (3가지 액션)**:
  * **`Click (클릭)`** (녹색): 매칭 성공 시 지정 좌표 1회 클릭
  * **`Double (클릭클릭)`** (파란색): 매칭 성공 시 설정된 더블클릭 간격으로 연속 2회 클릭
  * **`Back (뒤로가기)`** (주황색): 해당 팝업/광고가 감지되면 안드로이드 뒤로가기(Back 키) 전송
* **⏱️ 템플릿 지연 시간 설정 (Action Delay)**:
  * 템플릿 행의 **`⏱️ 0s`** 버튼을 클릭하여 동작 전/후 지연 시간(초 단위)을 설정할 수 있습니다.
  * `동작 전 대기` (인식 직후 클릭 전 대기) 및 `동작 후 대기` (클릭 완료 후 다음 탐색 전 대기)를 자유롭게 선택할 수 있습니다.
* **🖼️ 템플릿 이미지 썸네일 미리보기 (Hover Preview)**:
  * 템플릿 목록 행에 마우스 커서를 올리면(Hover), 해당 템플릿의 **원본 이미지 썸네일, 이미지 해상도(크기) 및 오프셋 좌표 정보**가 담긴 고급 팝업창이 플로팅 형태로 표시됩니다. 파일명이 모호해도 어떤 버튼인지 즉시 직관적으로 확인할 수 있습니다.
* **🖱️ 템플릿 우클릭 메뉴 및 이름 변경 (Rename)**:
  * 템플릿 행을 **마우스 우클릭**하면 컨텍스트 메뉴가 열려 **`✏️ 이름 변경 (Rename)`**을 통해 이미지 파일명과 설정 정보를 편리하게 바꿀 수 있습니다. (즉시 실행, 지연 시간 설정, 삭제 메뉴 지원)
* **실시간 클릭 수 합산 및 초기화**:
  * 여러 인스턴스에서 발생한 클릭 수는 실시간으로 합산되어 라벨에 반영됩니다.
  * **`Reset Counts`** 버튼으로 해당 탭의 누적 클릭 수를 0으로 초기화할 수 있습니다.
* **템플릿 삭제 (`X`)**: 목록 및 저장소 폴더에서 템플릿을 안전하게 삭제합니다.

## ⚙️ 5. 전역 공통 환경 설정 (Global Settings)

어느 탭에서든 **`⚙️ Settings`** 버튼을 누르면 전역 공통 설정 창이 열리며, **모든 인스턴스 탭에 실시간으로 즉시 공유 및 반영**됩니다.

| 설정 항목 | 기본값 | 설명 |
| :--- | :---: | :--- |
| **스캔 간격 (Scan Interval)** | `1초` | 화면 캡처 및 템플릿 탐색 주기 (초 단위) |
| **더블클릭(클릭클릭) 간격** | `1.0초` | 더블클릭 액션 및 특정 좌표 클릭클릭 시 1차 클릭과 2차 클릭 사이의 간격 (초 단위) |
| **동작 후 대기 시간 (Post-Action Delay)** | `2.0초` | 모든 동작(클릭/더블클릭/뒤로가기) 실행 후 다음 화면 탐색 전 공통 대기 시간 |
| **이미지 유사도 임계값 (Similarity Threshold)** | `0.9` | 이미지 일치 감도 (0.1 ~ 1.0, 높을수록 엄격하게 매칭) |
| **고속 그레이스케일 매칭** | `ON` | 흑백 변환 매칭으로 CPU 사용량을 대폭 절감 (색상 구분이 필요할 때만 OFF) |
| **매칭 없음 경고 알림 시간 (No-match Alert)** | `120초` | 설정 시간 동안 어떤 템플릿도 인식되지 않으면 경고 팝업 발생 (`0` 입력 시 알림 끄기) |
| **동일 템플릿 연속 매칭 경고 횟수** | `0` | 동일한 템플릿이 지정 횟수 이상 연속 매칭 시 무한 루프 감지 경고 팝업 발생 (`0` 입력 시 끄기) |
| **앱 실행 시 클릭 카운터 자동 초기화** | `OFF` | 프로그램 새로 실행 시 이전 템플릿 누적 클릭 수를 0으로 자동 초기화 |

> [!TIP]
> **스마트 알림 시스템**: 매칭 없음 경고 또는 연속 매칭 경고 발생 시 해당 인스턴스 탭으로 화면이 자동 전환되고 탭 리본과 헤더가 붉은색(`⚠️`)으로 강조되며, 사용자가 자리를 비워도 팝업창이 중복 누적되지 않도록 보호합니다. 다른 템플릿 매칭 시 정상 상태로 자동 복귀합니다.

## ⚡ 6. 미매칭 자동 동작 및 최종 예외 동작 (No-Match / Fallback Action)

장시간 화면이 멈추거나 예기치 않은 팝업/광고로 인해 기본 템플릿이 인식되지 않을 때 자동으로 수행할 복구 동작을 지정합니다.

### 🔹 A. 미매칭 자동 동작 설정 (`SettingsWindow`)
* **동작 대기 시간 (`Action Interval`)**: 미매칭 상태가 지속된 후 동작을 수행할 대기 시간 (기본값: `30초`)
* **동작 종류**:
  1. **`📋 미매칭 복구 템플릿 목록 매칭 (Fallback Match List)`** *(권장)*: `⚡ 미매칭 템플릿` 탭에 등록된 2차 복구 템플릿들을 순서대로 탐색하여 실행
  2. **`사용 안 함 (Disabled)`**: 아무 동작도 수행하지 않고 대기
  3. **`🎲 화면 랜덤 클릭 (Random Click)`**: 화면 중앙 안전 영역(가로 15~85%, 세로 20~80%) 무작위 좌표 1회 클릭
  4. **`👆 특정 좌표 클릭 (Custom Click)`**: 지정한 (X, Y) 좌표 1회 클릭
  5. **`✌️ 특정 좌표 클릭클릭 (Double Click)`**: 지정한 (X, Y) 좌표를 설정된 더블클릭 간격으로 2회 클릭
  6. **`↩️ 뒤로가기 (Back Key)`**: 안드로이드 뒤로가기(Back 키) 전송

---

### 🔹 B. 모든 미매칭 템플릿 불일치 시 최종 예외 동작 (`Final Fallback Action`)
`⚡ 미매칭 템플릿` 탭 하단의 **`📌 모든 템플릿 불일치 시 최종 동작`** 패널에서 설정합니다.

* **동작 원리**: 30초 대기 시간에 도달하여 등록된 미매칭 템플릿들을 모두 탐색했으나, **일치하는 템플릿이 하나도 없을 때 실행할 마지막 안전 장치**입니다.
* **지원 동작**:
  * `사용 안 함 (Disabled)`
  * `👆 특정 좌표 클릭 (Custom Click)` / `✌️ 특정 좌표 클릭클릭 (Double Click)`
  * `↩️ 뒤로가기 (Back Key)`
  * `🎲 화면 랜덤 클릭 (Random Click)`
* **`🎯 좌표 선택` 버튼**: 화면 캡처 창에서 원하는 위치를 클릭하여 X, Y 좌표를 즉시 설정합니다.
* **`⚡ 즉시 실행` 버튼**: 설정한 최종 동작이 에뮬레이터에서 올바르게 동작하는지 즉시 테스트합니다.

## 🛡️ 7. 성능 및 안정성 특장점

* **고속 ADB 직결 TCP 소켓 스트리밍 (Zero Subprocess)**: 매 프레임마다 `adb.exe` 프로세스를 생성/종료하던 방식을 탈피하고 ADB 서버(5037 포트)와 직접 TCP 소켓 스트림으로 통신하여 윈도우 프로세스 생성(`CreateProcess`) 오버헤드를 100% 제거하고 캡처 지연을 최소화했습니다.
* **단일 패스 템플릿 사전 캐싱 (Dual Grayscale & Color In-Memory)**: 템플릿 디코딩 시 컬러와 그레이스케일 변환을 인메모리 단일 패스로 처리하여 디스크 I/O 호출 및 반복 색상 변환 연산을 50% 절감합니다.
* **초고속 이미지 캐싱**: 이미지 수정 시각(`mtime`)과 크기를 감지하여 파일 변경 시에만 디코딩을 수행합니다.
* **축소 탐색 + 원본 국소 검증**: 축소 화면에서 찾은 상위 후보 주변만 원본 해상도로 검증하고, 실패할 때만 전체 화면으로 안전하게 폴백합니다.
* **템플릿별 동적 ROI**: 성공 위치 주변을 다음 검사 영역으로 재사용합니다. 새 템플릿을 화면에서 선택하면 해상도 독립적인 정적 ROI도 함께 저장됩니다.
* **정지 화면 생략 및 강제 재검사**: 직전 전체 검사가 미매칭이고 화면 CRC가 완전히 같을 때만 검사를 생략하며, 기본 5초마다 전체 검사를 강제합니다. 클릭과 뒤로가기 후에는 즉시 다시 검사합니다.
* **적응형 스캔 및 안전한 검색 순서**: 변화가 없는 동안 검사 간격을 안전한 상한까지 늘립니다. 전이 기반 순서 최적화는 사용자 액션 우선순위를 바꿀 수 있어 기본은 꺼져 있으며, 명시적으로 켜도 상위 3개를 고정하고 10회마다 원래 순서로 검사합니다.
* **단색(Flat) 템플릿 자동 보정**: 단색 이미지 매칭 시 발생할 수 있는 0분모 나눗셈 문제를 감지하여 `SQDIFF_NORMED`로 자동 전환합니다.
* **단일 원자 전역 설정 저장 (Atomic Save)**: 전역 공통 설정과 대기 중인 클릭 카운트를 한 스냅샷에 합쳐 한 번만 저장하며, 다중 인스턴스의 연결 상태를 안전하게 보존합니다.
* **클릭 카운트 지연 플러시**: 클릭 발생 시 메모리에 기록 후 5초 단위로 묶어 디스크에 원자적으로 저장합니다.
* **저지연 ADB 캡처 및 자동 복구**: 로컬 에뮬레이터는 raw 캡처를 우선 사용하고 PNG 및 ppadb 순으로 폴백합니다. 실패한 backend와 재연결에는 cooldown/backoff를 적용합니다.
* **고정 주기 다중 루프**: 캡처·매칭 시간을 주기에서 차감하며, 전체 인스턴스 시작 시점을 분산하여 CPU와 ADB 순간 부하를 줄입니다.
* **다중 인스턴스 OpenCV 스레드 최적화**: 5개 이상의 에뮬레이터를 동시 구동할 때 각 스레드에서 발생하는 OpenCV 워커 스레드 폭발을 차단하기 위해 `cv2.setNumThreads(1)` 및 OpenCL 충돌 방지(`setUseOpenCL(False)`)를 적용하여 CPU 컨텍스트 스위칭 렉과 UI 프리징을 원천 차단했습니다.
* **독립 ADB 데몬 자동 복구 및 콜드 스타트**: 외부 ADB가 실행되지 않은 상태에서도 구버전 없이 단독으로 안전하게 ADB 데몬을 시작하며, 한글 윈도우(CP949) 환경의 인코딩 충돌을 방지합니다.
* **선택적 롤링 성능 계측**: `performance_metrics`를 켜면 캡처·전처리·축소/국소/전체 매칭·액션 시간을 고정 크기 버퍼에 기록하고 `get_performance_stats()`로 확인할 수 있습니다. 평상시에는 계측 오버헤드를 없애기 위해 꺼져 있습니다.
* **Tkinter UI 스레드 디커플링**: 백그라운드 스레드와 UI 간 `queue.SimpleQueue` 메시지 펌프를 적용하여 프리징과 충돌을 방지합니다.

정확도를 바꾸지 않는 주요 최적화는 기본 활성화됩니다. 고급 사용자는 `config.json`의 `local_verify`, `dynamic_roi`, `frame_change_detection`, `force_scan_interval`, `adaptive_scan_interval`, `max_idle_interval`, `adaptive_template_order`, `capture_backend`(`auto`/`raw`/`png`), `performance_metrics` 값을 인스턴스별로 조정할 수 있습니다.

## ❓ 9. 자주 묻는 질문 (FAQ)

**Q1. 별도로 ADB를 설치하거나 환경 변수를 설정해야 하나요?**  
- 아닙니다. 프로그램 내부에 최신 ADB 실행 파일 및 종속 DLL이 번들링되어 있어 다운로드 후 바로 실행하시면 됩니다.

**Q2. 에뮬레이터 여러 대를 동시에 켤 수 있나요? (5개 이상 구동 팁)**  
- 네! 상단의 **`➕ 인스턴스 탭 추가`** 버튼을 눌러 `5555`, `5557`, `5559` 등 여러 에뮬레이터를 각각 탭으로 띄운 뒤 **`▶ 전체 시작`**을 누르면 독립적으로 동시 구동됩니다.
- **5개 이상 다중 구동 권장 팁**:
  1. 에뮬레이터 해상도를 `540x960` 또는 `720x1280`, `30 FPS`로 설정하시면 PC 부하와 ADB 캡처 병목을 대폭 줄일 수 있습니다.
  2. `⚙️ Settings`에서 `고속 그레이스케일 매칭`을 **ON**으로 사용하세요.

**Q3. 30초로 설정된 미매칭 템플릿이 동작하는지 어떻게 확인하나요?**  
- 상단 상태 바의 **`⚡ 미매칭 대기`** 카드에서 실시간 카운트다운을 확인할 수 있으며, 30초 도달 시 `Activity Log`에 검사 시도 및 매칭 결과가 상세하게 기록됩니다.

**Q4. 등록된 템플릿이 잘 작동하는지 테스트해보고 싶어요.**  
- 목록에서 원하는 템플릿을 **마우스로 더블클릭**하면 현재 화면에서 해당 템플릿을 탐색하여 즉시 클릭/동작을 수행합니다.

**Q5. 미매칭 템플릿으로도 해결되지 않는 팝업이나 화면 멈춤은 어떻게 하나요?**  
- `⚡ 미매칭 템플릿` 탭 하단의 **`📌 모든 템플릿 불일치 시 최종 동작`**에서 `뒤로가기` 또는 닫기 버튼 `특정 좌표 클릭`을 설정해 두시면 복구 템플릿이 모두 불일치하더라도 자동으로 해당 동작을 수행합니다.
